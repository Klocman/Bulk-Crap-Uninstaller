EBUninstaller Pro Documentation

The Ultimate Next-Generation Windows Uninstaller & System Maintenance Suite

.NET 8.0 Windows 10 / 11 (x64 & ARM64) 100% Offline-First Zero Telemetry Author: EhabYT

1. Overview & Architecture

EBUninstaller Pro is an advanced, modular, open-source software uninstaller designed to thoroughly remove software, eradicate remnants and residual files, monitor installations in real-time, optimize boot times, and maintain peak system hygiene.

Core Principles:

  • Safety First: Protected Windows paths and critical registry hives are guarded by SecurityGuard.
  • Cryptographic Integrity: Every backup and rollback trace is secured using SHA-256 digests.
  • Zero Background Services: Lightweight, standalone, and completely offline with no mandatory telemetry.

2. Modern Windows 11 Fluent Interface

EBUninstaller Pro features a sleek, responsive interface matching modern Windows 11 Fluent design principles:

  • 13-Section Command Bar: Instant 1-click navigation across all application modules.
  • Quick Filter Chips: Instant filtering by category (Win32, Store Apps, Games, Large Space Hogs).
  • Live Stats Dashboard: Real-time feedback on discovered applications, disk space, and selection sizes.
  • 3-Tab Application Inspector: Deep inspection of Authenticode digital signatures, certificate subjects, and registry identifiers.

3. Unified 10-Phase Uninstall Pipeline

When uninstalling applications, EBUninstaller Pro executes a structured 10-phase pipeline:

  1. Pre-Flight Verification: Validates target application and checks exclusion rules.
  2. System Restore Point: Generates a Windows VSS restore point.
  3. Cryptographic Pre-Backup: Exports targeted registry keys and files.
  4. Process Termination: Safely closes running application instances.
  5. Quiet Uninstallation: Executes official quiet uninstallation commands.
  6. Multi-Signal Leftover Scan: Deeply analyzes file system and registry for remnants.
  7. Confidence Scoring: Categorizes leftovers into High, Medium, and Low confidence.
  8. Controlled Removal: Cleans validated leftovers transactionally.
  9. Working Set Refresh: Updates system and explorer caches.
  10. Audit Logging: Logs operations to the persistent history store.

4. Forced Removal Engine

For broken, corrupted, or partially uninstalled software lacking an official uninstaller, the Forced Uninstall Manager scans directories, registry classes, COM objects, and services directly, allowing complete eradication without executing broken setup files.

5. Real-Time Installation Monitor & Snapshots

Track everything that software installers write to your system without unstable kernel drivers:

# Monitor an installer via CLI
EBUninstaller.exe monitor "C:\Installers\Setup.exe" --name "ToolName" --json

Traces are saved under %LOCALAPPDATA%\EBUninstallerPro\Traces\ and can be reviewed and rolled back with a single click.

6. Cryptographic Backup & Recovery Center

Before any destructive action, backups are created with SHA-256 verification:

Component File Description
Manifest manifest.json Package metadata, dates, and file hashes
Integrity Digest manifest.sha256 Tamper-proof cryptographic checksum
Registry Export registry.reg Standard Windows Registry Editor v5.00 script
File Archive files.zip Deflate-compressed application files and configs

7. Software Health & Hygiene Advisor

Calculates a System Hygiene Score (0–100%) by detecting:

  • Duplicate Runtimes: Multiple redundant Microsoft Visual C++ and Java installations.
  • Abandoned AppData: Folders left behind by uninstalled applications not modified in over 6 months.
  • Large Space Hogs: Applications consuming more than 5 GB of storage.

8. System Maintenance & Privacy Cleaners

EBUninstaller Pro includes specialized maintenance engines:

  • Junk Cleaner: Purges Windows Temp, SoftwareDistribution updates, crash dumps, and DirectX shader caches.
  • Privacy Cleaner: Removes cookies, histories, and download caches across Chrome, Edge, Firefox, Brave, and Opera.
  • Registry Optimizer: Repairs dead App Paths, broken SharedDLL entries, and orphaned MUI caches.
  • Memory Trimmer: Reclaims standby working set RAM.

9. Startup & Boot Optimizer

Analyzes Windows startup entries across Run, RunOnce, Scheduled Tasks, and Services. Classifies items into impact ratings (None, Low, Medium, High, VeryHigh) to accelerate Windows login times.

10. Command Line Interface (CLI)

# Discovered application listing
EBUninstaller.exe list --json

# Quiet uninstallation with high confidence leftovers
EBUninstaller.exe uninstall "VLC media player" /Q /U /J=VeryGood

# Forced removal by folder
EBUninstaller.exe forced-uninstall "C:\Program Files\BrokenTool" /U

# System health and memory trim
EBUninstaller.exe health
EBUninstaller.exe trim-memory

12. Security & Guard Architecture

All operations pass through SecurityGuard. Critical system components (e.g. C:\Windows\System32, WinSxS, HKLM\SAM, HKLM\SECURITY) are strictly protected against deletion.
