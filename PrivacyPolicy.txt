================================================================================
EBUninstaller Pro - Privacy Policy & Offline Guarantee
================================================================================

EBUninstaller Pro is an open-source, privacy-first Windows uninstaller and system
cleanup utility.

1. ZERO TELEMETRY & ZERO TRACKING
   EBUninstaller Pro DOES NOT collect, transmit, or store any personal data, 
   usage statistics, application inventories, hardware fingerprints, or telemetry.
   The core uninstaller functions 100% offline.

2. LOCAL DATA STORAGE
   All application configurations, exclusions, operation history logs, traces,
   and backups are stored strictly locally on your computer in your local user profile:
   - %LOCALAPPDATA%\EBUninstallerPro\

   None of this information is ever uploaded or transmitted across the internet.

3. OPTIONAL UPDATE CHECKS
   If you explicitly check for application updates, EBUninstaller Pro queries the
   public GitHub Releases API over HTTPS to retrieve the latest version tag.
   No device identifiers or personal parameters are attached to update queries.

4. USER RIGHTS & OPEN SOURCE
   EBUninstaller Pro is licensed under the Apache License, Version 2.0. You are
   free to inspect, modify, and audit all source code directly in the repository.

If you have questions regarding this policy, please open a discussion on the GitHub repository.
